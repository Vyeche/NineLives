# The cat

A small cat sits at the right end of the **+ New tab** line. It sums up every tab at once, so a glance at
one spot tells you whether anything wants you. The most important mood wins:

| Face | Means |
| --- | --- |
| `=O.O= !` | a tab needs you (`2!` = two tabs). The `!` blinks at first, then stays |
| `=^▽^=✦` | you just earned a badge (`♛` = a new rank) |
| `=^ω^= ♪` | a tab just finished (`♪♪`, `♪♪♪`: two or three in a row, each within 90 s) |
| `=>.<=` | something just failed |
| `=^.^= ~` | tabs are working (the tail swishes) |
| `=^.^=` | nothing going on (it blinks now and then) |
| `=-.-= zZ` | nothing has worked or waited for 3 minutes: it naps |

"Needs you" always wins, even over a celebration.

Once it is fully asleep it stops changing, so an idle kitty doesn't redraw at all.

```bash
kitty-cat          # show this list
kitty-cat off      # hide the cat
kitty-cat on       # bring it back
```
